# C++ source code

This folder contains different implementation of ICT using C++.

### dataStructures folder:

Contains implementation of various data structures from scratch that are used in other technologies.
These implementations are raw and simplified. Self-implemention of the data structures is an educational experiment, therefore only necessary functionality is implemented.

### networkDevices folder:

Contains implementation of the devices and functions that allows network development and interaction within it.

### routing folder:

Contains implementation of routing protocols that are used in networks.
